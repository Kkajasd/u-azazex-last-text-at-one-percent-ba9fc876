A program that writes the last text message a phone sends at one percent battery to `/output/entry.txt`. The message is fixed and deterministic — the same line on every run, no network, no input files. Built by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

The text it writes:

> i have 1% left and i'm spending it texting you instead of calling 911. that's how much i love you. also delete my search history.
